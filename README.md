# 云木搭搭 · 云和木玩创意拼搭游戏

一个可直接打开的手机竖屏网页小游戏。玩家跟随云和祥龙的故事线，把每一关的木玩零件自由摆放到图纸中，完成 12 张图纸，收集自己的云木作品。

## 已实现功能

- **12 关完整故事**：每关拥有独立图纸、零件组合和开场对白；完成第 12 关后进入“云海工坊”结局。
- **自由拼搭**：零件不自动吸附，支持单指拖动、点击选中、90°旋转、删除、撤销和清空；完成时按照位置与角度计算作品完成度和奖励。
- **移动端操作**：竖屏布局、触控拖动、双指缩放画布、底部导航和大尺寸操作按钮。
- **云和祥龙引导**：关卡对白、演示试玩、完成时的祥龙/云朵/木屑动效。
- **木玩币工坊**：使用木玩币解锁云海、夕照、森林、星夜画布；蜂蜜、彩漆、雪松零件外观；云朵、树木、旗帜、祥龙贴纸。
- **作品图鉴**：每关完成后保存当前画布、零件外观、贴纸、作者昵称、得分和完成度；回到已完成关卡可以继续修改并覆盖图鉴作品。
- **本地账户**：支持多个本地昵称账户，每个账户单独保存关卡进度、得分、木玩币、工坊解锁和图鉴；也可以游客试玩而不保存进度。
- **声音反馈**：Web Audio API 生成舒缓背景音乐，并提供拿起、放下、旋转、删除、完成和木玩币反馈音；手机支持可选轻微震动。
- **作品导出与分享**：图鉴、结算页和个人页可导出当前作品 SVG 图片；支持系统分享，浏览器不支持时自动复制分享文案。
- **比赛展示入口**：首页包含创作说明、AI 辅助说明、演示试玩入口和 1–3 分钟演示路径，便于准备赛道三展示材料。

## 运行与发布

直接打开 `index.html` 即可运行，不需要 Node.js、数据库或后端服务。发布到 GitHub Pages、Netlify 或 Vercel 等静态托管服务后，用户点击链接即可游玩。

本地账户使用浏览器 `localStorage` 保存，只在当前浏览器和设备有效。清除浏览器数据会删除本地存档；作品导出和分享不上传服务器。

在线试玩：[https://yolo-xggw.github.io/-/](https://yolo-xggw.github.io/-/)

## 赛道三展示建议

演示时可从“演示试玩”开始，再进入第 1 关展示对白、自由拖动、旋转和完成反馈；打开木玩工坊购买一个画布或贴纸，回到画布装饰作品，最后在图鉴导出作品卡片。正式提交时请结合实际创作记录整理 AI 生成比例、过程截图、1–3 分钟演示视频和竖版 A3 海报。

## 设计依据

零件造型参考积木、圆榫、半圆、拱形护栏、木轮、轨道、城堡和交通玩具，将云和木玩中常见的原木、云海蓝、松林绿、陶土红与蜂蜜黄转化为轻量数字拼搭体验。
