# 云木搭搭｜云和木玩创意拼搭游戏

一个可直接打开的静态网页小游戏，面向手机竖屏体验。玩家在 12 张云和童话主题图纸中，用圆角木块、木轮、拱形护栏、塔楼、风车叶片等零件自由拼搭作品。

## 当前功能

- 12 个关卡，每关使用独立的木玩零件套件和图纸轮廓。
- 木玩零件采用自然木色、松木绿、云朵蓝、陶土红和蜂蜜黄，带有木纹、倒角和柔和阴影。
- 零件按对应虚线轮廓的宽高自适应，曲线部件使用拱形、圆角、椭圆、梯形和三角形造型。
- 单指拖动、旋转、删除、撤销和重置；不自动吸附，作品可以自由摆放。
- 手机端支持双指缩放画布，便于查看小尺寸曲线和细节。
- 本地昵称账号：每个用户独立保存关卡、得分、木玩币、当前画布和图鉴作品。
- 完成关卡后把当前画布收录为图鉴缩略图；回玩并重新完成后会覆盖为最新作品。
- 用户页可以选择已经到达的关卡并恢复之前保存的作品。
- 使用 Web Audio API 生成舒缓旋律，不加载外部音频资源。
- 手机端采用奶油木纸、胡桃木墨和云朵蓝行动色，加入底部导航、故事引导、放置进度和参赛创作说明，打开链接即可理解玩法。

## 运行与发布

直接打开 `index.html` 即可运行，不需要 Node.js、数据库或后端服务。发布到 GitHub Pages、Netlify 或 Vercel 等静态托管服务即可公开访问。

本地账号数据使用浏览器 `localStorage` 保存，仅在当前浏览器设备有效；清除浏览器数据后存档会被清除。

## 赛道三适配

项目按“AI小游戏类”的木玩拼图/搭建方向制作，包含云和童话叙事、可交互的12关拼搭流程和可实际运行的移动端网页版本。首页的“创作说明”会展示主题、AI协作内容、演示路径和运行方式；提交前应结合自己的实际创作记录整理AI生成比例、过程截图、1–3分钟演示视频及竖版A3宣传海报。

## 设计依据

零件造型参考云和木玩常见的积木、圆柱、半圆、拱形、木轮、轨道、城堡和交通玩具，让现实中的木玩结构转化为轻量的数字拼搭体验。
